# Circuit Comfort Professional

Aplicació multipàgina separada per carpetes.

## Estructura

- index/index.html, index/index.css, index/index.js
- login/login.html, login/login.css, login/login.js
- registre/registre.html, registre/registre.css, registre/registre.js
- circuit/circuit.html, circuit/circuit.css, circuit/circuit.js
- transport/transport.html, transport/transport.css, transport/transport.js
- alertes/alertes.html, alertes/alertes.css, alertes/alertes.js
- menjar/menjar.html, menjar/menjar.css, menjar/menjar.js
- perfil/perfil.html, perfil/perfil.css, perfil/perfil.js

## Funcionalitats

- Registre obligatori abans d'iniciar sessió.
- Validació de correu electrònic.
- Login amb comprovació d'usuari i contrasenya.
- Sessió guardada amb localStorage.
- Pàgines privades protegides.
- Menú inferior fix sense tapar contingut.
- Mapes interactius amb Leaflet centrats al Circuit de Barcelona-Catalunya.
- Cada pàgina té el seu propi HTML, CSS i JS.
